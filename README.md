# Over My Dead Body · 醉隱

連假前夕，吉姆又一次加班到失去意識。醒來後他只想回家睡覺，這趟路卻走了整整七天。

一個網頁平台跳躍原型：單畫面房間、固定鏡頭（Celeste 式），靠抽卡發動「醉隱」能力過關。

## 檔案

| 檔案 | 說明 |
|---|---|
| `prototype/game.html` | 遊戲本體。單一檔案，雙擊即可玩，也可以直接貼上 BeaverKit |
| `prototype/editor.html` | 關卡編輯器。單一檔案，匯出 `drunken-rooms` v2 JSON 給遊戲載入 |
| `dist/`、`server.mjs`、`tests/` | 早期版本（已不使用），留作參考 |

兩個網頁不共用程式碼，只靠 JSON 交接。美術素材直接讀取 BeaverKit 上的網址，開啟時需要連網。

## 操作

| 按鍵 | 作用 |
|---|---|
| A / D | 移動 |
| W / 空白鍵 | 跳 |
| K | 開始抽卡 → 再按 K 鎖定 → 喝完後 5 秒內按 K 發動 |
| R | 重來這間 |
| Esc | 暫停、載入關卡 JSON |
| M | 靜音 |
| ` | 手感調整面板 |

## 能力

- **摔角手**：醉隱把吉姆舉起來，選方向後丟出去。
- **保鑣**：醉隱扛著吉姆以固定速度衝刺，撞碎箱子、撞飛保全，可以踩過碎玻璃。

抽卡規則：
- 抽卡和喝酒時世界放慢到 0.2 倍。
- 正在作用中的技能抽不到。
- 離地後只能抽 1 次，落地重置。

## 試玩自訂關卡

編輯時可按「試玩目前房間」，直接在編輯器內從選取的房間開始玩，包含尚未匯出的修改。按「結束試玩 · 返回編輯」繼續編輯；每次開啟試玩都會重新載入最新內容。請將 `editor.html` 與 `game.html` 放在同一個資料夾。

1. 用 `editor.html` 畫好關卡，按「匯出 JSON」。
2. 開 `game.html`，按 Esc →「載入關卡 JSON」，或直接把檔案拖進遊戲畫面。

## NPC 與對話

選取 NPC 後，右側的視覺對話工具可修改名稱、選起始段落、新增對話段落與回答選項。各段落／回答的目的地下拉選單可連接到另一段落或結束對話。欄位變更後自動儲存，支援復原／重做；「試播對話」可直接點選回答測試分支。JSON 編輯放在「進階：對話 JSON」中，原有匯入與匯出功能保留。

在編輯器選 **NPC** 工具放置 `N` 格子，再點已放置的角色（或選右側 NPC 座標）。右側可直接修改對話 JSON 並按「套用對話」，或按「匯入對話檔」載入 `prototype/dialogue-example.json` 這種格式。每個 NPC 獨立設定；匯出關卡 JSON 會包含所有對話。擦除角色會移除其對話。

遊戲中靠近 NPC 按 **E** 開始交談，**E / Enter** 繼續，**1–9** 選回答。交談時暫停角色與世界。`name` 是角色名稱，`start` 是起始節點 ID，`nodes` 包含各節點的 `text` 和 `next`，或 `choices`（每個回答有 `text`、`next`）。`next: null` 結束對話；其他 `next` 必須指向既有節點。每節點最多 9 個回答，文字最多 500 字、回答最多 100 字。

關卡中 `npcs` 以格子座標儲存，例如 `"npcs": { "6,15": { "name": "NPC", "start": "hello", "nodes": { "hello": { "text": "你好！", "next": null } } } }`。

## 格子代號

`.` 空白、`#` 地形、`^` 碎片、`=` 木板、`B` 箱子、`C` 紙箱、`>` `<` 輸送帶、`R` 巡邏、`L` 掉落物、`*` 瓶蓋、`P` 出生點、`N` NPC。房間固定 32 × 18 格。

傳送門：在編輯器選「傳送門」放置 `O` 格子，玩家碰到後會前往房間列表的下一間。最後一間的傳送門會結束這一天，按確認進入下一天。可用房間「往前／往後」調整順序，傳送門可取代畫面邊緣出口。

每個傳送門可有自己的目的地。在房間設定先選傳送門座標，再選同一天的目的房間或「結束這一天」。也可選傳送門工具並點擊已放置的傳送門來選取。JSON 使用 `portalTargets`，例如 `{"6,15":"1-2","10,15":null}`。未個別設定的傳送門沿用舊的 `portalTarget` 或列表下一間；擦除傳送門會移除其設定。
