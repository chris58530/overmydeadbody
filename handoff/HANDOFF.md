## 2. 怎麼跑

```bash
git fetch origin
git checkout drink-loop-prototype
git pull
python -m http.server 4174 --bind 127.0.0.1 --directory prototype
```

- 從頭玩：`http://127.0.0.1:4174/game.html?chill=loop`
- 直接到某間：`http://127.0.0.1:4174/game.html?chill=loop&room=L3-2`
- 不開伺服器：雙擊 `prototype/beaverkit.html`，已內嵌 loop 關卡和 P 路線，也可以加 `?room=L3-2`。
- **容易看錯：** 雙擊 `game.html` 或不加 `?chill=loop`，會載入內建舊關卡，第一招是「丟」。這不是 bug，但使用者曾因此以為版本錯了。

## 3. 改完關卡的流程

```bash
node handoff/kit/chill-loop.mjs
node handoff/kit/build-beaverkit.mjs
node --test tests/*.test.mjs
```

1. 第一行錄製並重播每間的 P 路線，寫入 `chill-loop.json`、`chill-loop-routes.json`。每間都必須有 P 路線，有調酒的房間 P 要拿到。
2. 第二行重建單檔版；`game.html` 或關卡有改就要跑。它寫出 `beaverkit.html`（三天合一）和 `beaverkit-day1/2/3.html`（每天一個，上傳 BeaverKit 用這三個）。
3. 有背景圖的房間：圖放在 `prototype/art/day3/`（WebP），本機直接讀；單檔版改讀 BeaverKit 素材庫的網址，網址是檔案內容的 SHA-256，由建置算出。**圖片改了或新增了，要先上傳到 BeaverKit 素材庫，否則線上版會變回灰盒子。** 開場會先下載全部圖片，畫面顯示「載入中」，載完才開始（最多等 8 秒，之後用灰盒子頂替），所以不會先閃灰盒子再跳成圖片。
4. **更新既有作品：** 自動化打開既有作品的編輯頁再匯入，頁面一定會凍結（2026-11-04、11-05、11-10 都是）。自動化只能從工作室「建立」開新作品（會拿到新連結）；要保留連結，請使用者自己在編輯頁按「匯入」選 zip 再按「更新」。
5. 目前 137 個測試全過。

**捷徑檢查的限制：** `node handoff/kit/chill-probe.mjs <房間id> --campaign=loop --mode=full` 在屍體房的 bug 已修，但束寬 800、12 秒的上限連 3-1、3-3 的已知解法都找不到，所以「NO」不能當作沒有捷徑。要確認某條路能不能走，請自己寫腳本掃起跳點和按鍵時機（`3-2` 就是這樣驗的）。

## 4. 目前規則

**共通**
- 碰到酒瓶就喝，醉意 +1；酒瓶離開後 3 秒重生。
- K 放屁是空中二段跳，用掉 1 格醉意；空中碰到酒瓶可補回。
- 世界是「三秒前的身體」：醉意改變後，地形三秒後才跟著變。幻覺實心格落在 Jim 身上會直接死。
- 沒有文字，只有房間編號；還沒拿到的技能、天數、醉意都不能出現在畫面上。
- 每天是一張連續地圖，鏡頭像 Celeste 一樣平移。第三天會往右、往上和往下（`climb()`）：往上從下一間地板的單向平台進入，往下是地板的洞，下一間天花板同一個位置也有洞。
- 調酒相當於 Celeste 的草莓：很難拿，要落地才算，死掉就失去。

**第三天（只有這天有屍體）**

- 2026-11-09 與使用者決定：醉意只有一種資源，地圖只有「醉」和「醒」兩張。第三天上限一瓶，所以 J 只會放屍體，「丟」暫時不開。
- 一瓶酒只能做一件事：放屁用一瓶，放屍體也用一瓶。以後的招式「招越大用越多瓶」（丟要兩瓶、用兩瓶），還沒做。
- 畫面：Jim 身上有醉色光暈（`STAGE_TINT`），頭上浮著 J 現在會出的招；放屁的煙是他失去的那個顏色；清醒時按 K 只有一小團灰煙和提示音。

| 醉意 | 按 J |
|---|---|
| 0 瓶，或還沒喝過酒 | 收回最後一具屍體（見下方防呆） |
| 1 瓶 | 原地留下浮空屍體（只能從上方踩），主角傳回最後喝的那瓶酒 |

- 綁著屍體的酒瓶保持空瓶，用虛線連到屍體。走開再走回空瓶：屍體消失、酒瓶回來。
- **防呆：** 0 瓶時按 J，最後一具屍體消失、主角傳回它的酒瓶，在哪裡都能用。測試也掃過，沒放屍體時每個站得到的位置都走得到酒瓶或出口（站在台車上算安全，台車一定會開回起點）。
- 引擎還支援屍體壓感應區（H）開門（G）或撐橋（g）、擋天花板雷射（V）、擋轉椅與警衛，但新的五間都沒用到；這些機關改在測試用的小房間裡測。使用者說過**不要雷射**。
- J 和 K 一樣會扣醉意，所以放屍體三秒後，喝醉才有的地形會消失，屍體留著。
- 屍體不限數量、不會自己消失；死掉或換房間時全部清掉。
- 使用者原則：**不能靠按重來才解得開**。

2026-11-09 整個重做：舊的十間設計得不好，使用者同意直接取代（舊版在 git 的 `a747ce2`）。節奏是「想」和「爽」交錯。

**使用者第二輪回饋（同日）：太鬆散、沒挑戰性、沒有連續性，每一步做完都能站著等到天荒地老。** 等待可以有，但不要頻繁。改法：
- 每間最多一個能停下來的地方（起點或酒瓶旁）。
- 3-2 台車改快（房間可設 `cartSpeed`，這間 220，預設 120）、軌道縮短，軌道上方吊一片玻璃要邊坐邊跳。
- 3-4 放屍體三秒後，清醒才有的牆會落在屍體上方（站著不走會被夾死），所以跑回屍體後要馬上跳走；警衛走道縮短。
- 3-5 兩瓶酒都在輸送帶上，被傳回酒瓶時會直接被帶向玻璃。

**第三輪回饋（同日）：每間看起來只有一題，平路太多。** 重走沒關係，但不要讓玩家在平路上一直走；小縫隙、簡單的也可以。改法：把平路換成小障礙。
- 3-1 出口前加玻璃坑和一個小台階。
- 3-2 牆頂加兩個玻璃坑（天花板拉高，跳得過）。
- 3-3 平台中間斷一段，要跳過去。
- 3-4 喝醉才有的橋中間斷兩格，三秒賽跑時也要跳；下層地板加玻璃坑。
- 3-5 入口平台下面整片是玻璃，要跳到輸送帶前的小地板，中間有一個會塌的紙箱可以墊腳。
- 之後可以再加的方向（使用者看過、還沒做）：每間考兩三種不同的屍體用法，例如擋警衛、傳送回高處、選喝哪瓶酒、收回屍體。
