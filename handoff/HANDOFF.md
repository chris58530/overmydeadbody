**接手請只看這一節。** 後面的「舊交接」是更早的玩法，只留作背景。

## 1. 專案與分支

- 專案：醉隱 Over My Dead Body，網頁平台跳躍原型。
- 分支：`drink-loop-prototype`。
- 主力版本：`prototype/game.html?chill=loop`，關卡定義在 [kit/chill-loop.mjs](kit/chill-loop.mjs)。
- 線上版（知道連結才能看）：https://beaverkit.io/p/ngneLMrUCiZ。**目前還是舊版第三天**，見第 6 節。

## 2. 怎麼跑

```bash
git fetch origin
git checkout drink-loop-prototype
git pull
python -m http.server 4174 --bind 127.0.0.1 --directory prototype
```

- 從頭玩：`http://127.0.0.1:4174/game.html?chill=loop`
- 直接到某間：`http://127.0.0.1:4174/game.html?chill=loop&room=L3-2`

## 4. 目前規則

**共通**
- 碰到酒瓶就喝，醉意 +1；酒瓶離開後 3 秒重生。
- K 放屁是空中二段跳，用掉 1 格醉意；空中碰到酒瓶可補回。
- 世界是「三秒前的身體」：醉意改變後，地形三秒後才跟著變。幻覺實心格落在 Jim 身上會直接死。
- 沒有文字，只有房間編號；還沒拿到的技能、天數、醉意都不能出現在畫面上。
- 每天是一張連續地圖，走出右邊進下一間，鏡頭像 Celeste 一樣平移。
- 調酒相當於 Celeste 的草莓：很難拿，要落地才算，死掉就失去。

**第三天（只有這天有屍體）**

| 醉意 | 按 J |
|---|---|
| 0 格，或還沒喝過酒 | 沒作用 |
| 1 格 | 原地留下浮空屍體（只能從上方踩），主角傳回最後喝的那瓶酒 |
| 2 格 | 醉影把主角丟出去 |

- 綁著屍體的酒瓶保持空瓶，用虛線連到屍體。走開再走回空瓶：屍體消失、酒瓶回來。
- J 和 K 一樣會扣醉意，所以放屍體三秒後，喝醉才有的地形會消失，屍體留著。
- 屍體不限數量、不會自己消失；死掉或換房間時全部清掉。
- 使用者原則：**不能靠按重來才解得開**。

|---|---|---|
| 第一天（4 間） | P1-1～P1-4 | 辦公室序章，只能跑跳 |
| 第二天（8 間） | L2-1～L2-8 | 喝酒、放屁、三秒時間差、輸送帶、台車、警衛 |
| 第三天（7 間） | 見下表 | 屍體，再來是丟 |

| 房 | 名稱 | 醉意上限 | 重點 |
|---|---|---|---|
| L3-1 | 留位置 | 1 | 放屍體當踏板過坑（教學，刻意保留舊設計） |
| L3-2 | 趁橋還在 | 1 | 跑到橋尾跳出去放屍體，三秒內跑回橋上再過去 |
| L3-3 | 放不放 | 1 | 三條路：只放屁、屍體 + K、兩具屍體 |
| L3-4 | 沙發 | 沒有酒 | 從原 3-2 移來，內容不變 |
| L3-5 | 丟 | 2 | 原房間，多一瓶酒 |
| L3-6 | 丟上沙發 | 2 | 原房間，多一瓶酒 |
| L3-7 | 醉了又醒 | 2 | 原房間，多一瓶酒；也是後段唯一用到三秒地形的房間 |

**已驗證**
- 3-2：從橋尾跳加 K，最遠 x=1171，需要 1178，掃 204 種起跳點與時機都過不去（只差 7 像素）。
- 3-3：只放屁能過，起跳 x≥約 540～560，K 要在最高點後約 0.1 秒內。兩具屍體路線用腳本實測能上牆並拿到調酒。

**前四間上限維持 1 格的原因：** 酒瓶三秒會重生，解鎖後等一下就能連喝兩瓶，提前用「丟」跳過房間。我曾向使用者提議解鎖，實作時改回不解鎖，並已告知。

**沒有驗證**
- **都沒有真人試玩。** P 路線只證明機器（240 Hz）做得到。
- 3-2 跑回橋上的時間餘裕（估算：約 1.5 秒跑到橋尾，橋 3 秒後消失）。
- 「醒來的位置是最後喝的那瓶酒」現在沒有房間強制教。
- 3-5 到 3-7 可能有別解，例如放屍體加放屁。

## 1. 目標（使用者已拍板的設計）

主角喝醉後發現會出現「醉影」幫他回家，於是開始控制醉的程度：越醉，醉影越強，但幻覺讓地圖越危險。

**唯一資源：酒精量表**
- 每天的格數上限 `cells`：第一天 1 格、第二天 2 格、第三天 3 格。
- 能量（`booze`）**會自動回復**：醉意自己上來。
- **已拿掉酒瓶**，使用者的決定。

**K：放屁**
- 只能點按，不能按住。冷卻 0.14 秒，要一直點（Flappy Bird 式）。
- 每噴扣 1/6 格。
- 按住 A／D：往前加速（氮氣）。不按方向或按住 W：往上噴。

**J：醉影**
- 一次用掉全部滿格，**連段全自動演完**。這是使用者明確選的「全自動」，不是逐段按。
  - 1 格：丟
  - 2 格：衝 → 丟
  - 3 格：升天（主角放超大屁）→ 衝 → 丟
- 最後一定是「丟」，因為醉影丟完就放手了。

**醉階**
- 醉階＝滿格數，每階可疊加地圖覆蓋層（`stages`）。越醉越危險，也可以有幻覺平台。
- 醉階要變之前會先預告約 0.9 秒，落地才會真的切換。
- 預告期間放屁讓那一格不滿，就能取消。

**流程要求**
- 使用者要求：手感好、關卡符合角色邏輯、好玩。
- 不要一開始技能全開，從第 1 格開始，到第三天才 3 格。
- 使用者最後說：**「直接改，不要審查，我來就好，趕快改」**。不要再跑子代理盲測流程。
